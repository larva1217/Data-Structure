# 📚 자료구조 (Data Structure)

본 과목은 컴퓨터를 이용한 문제 해결의 근간이 되는 자료구조의 개념을 학습한다. 자료구조와 관련된 다양한 알고리즘을 배우고 구현함으로써 효율적인 프로그램 설계 및 개발 능력을 향상시키는 것을 목표로 한다. 또한 Java 언어를 활용하여 자료구조를 구현하고 활용하는 방법을 학습한다.

## 📖 학습 내용
- 자료구조의 기본 개념 이해
- 배열(Array)과 연결 리스트(Linked List)
- 스택(Stack)과 큐(Queue)
- 트리(Tree)와 이진 탐색 트리(Binary Search Tree)
- 힙(Heap)과 우선순위 큐(Priority Queue)
- 해시 테이블(Hash Table)
- 그래프(Graph)와 그래프 탐색 알고리즘
- 정렬(Sorting) 및 탐색(Searching) 알고리즘
- 알고리즘의 시간 복잡도와 공간 복잡도 분석

## 💻 개발 환경
- Language: Java
- IDE: Eclipse
